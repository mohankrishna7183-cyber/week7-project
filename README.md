# DG Interns Hub – Job & Internship Landing Website

A responsive **Job and Internship Landing Website** built using **React JS** as part of the DG Interns Hub Week 7 task.

## 📌 Project Overview

DG Interns Hub is a web platform designed to help students and freshers explore internship and job opportunities in one place.

Users can browse available opportunities through job cards, view important job details, and use the Apply Now option to explore opportunities.

## 🎯 Objective

The objective of this project is to build a responsive and user-friendly job and internship landing website using React JS.

The project demonstrates:

* React functional components
* React Router
* Reusable components
* Job listing cards
* Responsive web design
* Navigation between multiple pages

## 🚀 Features

* 🏠 Home page
* 💼 Job and internship listings
* 📋 Job cards with opportunity details
* 🔗 Apply Now buttons
* 📞 Contact page
* 🧭 React Router navigation
* 📱 Responsive design
* 💻 Desktop and mobile support
* 🎨 Clean and user-friendly interface

## 📄 Pages

### Home

The Home page introduces DG Interns Hub and provides users with an overview of the platform and featured opportunities.

### Jobs

The Jobs page displays internship and job opportunities in card format.

Each card includes:

* Job title
* Company name
* Location
* Required skills
* Stipend/salary
* Apply button

### Contact

The Contact page provides a form where users can enter their name, email, and message.

## ⚙️ Installation and Setup

Clone the repository:

```bash
git clone https://github.com/mohankrishna7183-cyber/week7-project.git
```

Navigate to the project folder:

```bash
cd week7-project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```
